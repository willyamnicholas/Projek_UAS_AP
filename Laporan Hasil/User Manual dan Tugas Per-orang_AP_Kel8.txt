User Manual:
1.Buka aplikasi KATKA
2.Klik Play/Quit.
3.Pada halaman awal, pemain diminta untuk memasukkan nama pengguna (username). 
4.Setelah memasukkan nama, pemain dapat memilih mode permainan: 
  •Mode Normal → bermain tanpa batas waktu, tetapi terdapat penghitung waktu untuk mencatat lama permainan. 
  •Mode Hard → permainan menggunakan batas waktu selama bermain. 
5.Setelah mode dipilih, sistem akan secara otomatis menentukan satu kata rahasia. 
6.Pemain mengetik kata tebakan menggunakan keyboard yang tersedia pada layar. 
7.Tekan tombol Enter/Kirim untuk memeriksa jawaban. 
8.Setiap huruf pada tebakan akan berubah warna sebagai petunjuk: 
  •Hijau → huruf dan posisi benar. 
  •Kuning → huruf benar tetapi posisi salah. 
  •Abu-abu → huruf tidak ada dalam kata. 
9.Permainan berakhir ketika pemain berhasil memasukkan kata yang benar atau ketika batas percobaan/pengisian kata telah habis. 
10. Bagikan Hasil Permainan: Setelah permainan selesai, akan muncul tangkapan layar hasil permainan, Gambar tersebut akan tersimpan dan secara otomatis membuka halaman WhatsApp Web, sehingga kamu dapat langsung mengirimkannya kepada teman atau kenalan kamu..
